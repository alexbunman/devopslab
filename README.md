# devopslab

Labo DevOps hybride d'alex : Proxmox sur un mini PC fanless à la maison, site secondaire Oracle Cloud, sauvegardes hors site sur AWS S3. C'est aussi le projet présenté au jury du titre RNCP36061 « Administrateur Système DevOps » (mars 2027).

Le service existant (n8n sur le Pi 3) est documenté dans le dépôt voisin `../pi3-n8n` (README et RUNBOOK).
